# Financy — Front-end

React + Vite + TypeScript + Apollo Client (GraphQL) + TailwindCSS.

```bash
cp .env.example .env   # VITE_BACKEND_URL=http://localhost:4000/graphql
npm install
npm run dev            # http://localhost:5173
```
